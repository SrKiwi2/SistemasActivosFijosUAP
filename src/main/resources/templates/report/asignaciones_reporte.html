Reportes / Reporte de Asignaciones

Listado de actas para exportar a Excel — una sola, el conjunto filtrado ("por rango") o todas ("general", sin filtros). Los campos Hoja de Ruta, Certificación y Comprobante se completan acá con el botón de cada fila — sirve también para actas que ya existían antes de este módulo o que ya se subieron al VSIAF. Sistematizado por no se pide: es quien registró el acta en el sistema.
